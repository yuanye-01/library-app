# library-app —— 图书借阅管理系统（WEB前端框架技术 期末大作业 · G1）

面向高校图书馆的借阅业务系统：读者在线检索与借阅，管理员维护藏书与借还台账。

## 技术栈

Vue 3（选项式 API）+ Vite + Vue Router（动态 / 嵌套 / 守卫 / 懒加载）+ Element Plus（PC 端）+ Vant（移动端）+ Axios + Pinia + pinia-plugin-persistedstate + json-server。

## 启动（两个窗口）

```bash
# 窗口 1：起后端接口（3001 端口）
npm run server

# 窗口 2：起前端页面（5173 端口）
npm run dev
```
